# Codex / Framer Implementation Notes

## Do This

- Build page by page, starting with the homepage.
- Use the UX copy as content inventory, not as layout instructions.
- Follow Marlund’s section rhythm and image-led composition.
- Keep copy short on the actual UI.
- Use image placeholders immediately, even before final photography is available.
- Use menu rows, category anchors, and selected featured images instead of item cards for every menu item.
- Keep Odoo ordering as a linked/redirected flow.

## Avoid This

- Do not create dense card grids.
- Do not paste every menu item onto the homepage.
- Do not build all pages in one pass.
- Do not use generic SaaS landing-page patterns.
- Do not use stock images permanently if real Cello photos become available.

## First Iteration Task

Build the homepage only using the structure above. Match Marlund’s spacious, editorial, restaurant-template feel before adding more pages.
